# Mindlogic Docs

> Mindlogic Docs is the official documentation site for Mindlogic products including FactChat, FactChat Admin, FactChat API Gateway, company guides, Informe, and support resources. Use this file as an LLM-friendly index to find the most important product, admin, API, integration, and policy pages.

This file follows the llms.txt proposal from https://llmstxt.org/: a single H1 title, a short blockquote summary, optional interpretation guidance, and H2 sections containing curated Markdown link lists.

The canonical docs domain is https://docs.mindlogic.ai. Most product documentation is served under `/docs/{tenant}/{product}/{pageGroup}/{pagePath}`. Use `general` as the public fallback tenant when a customer-specific tenant slug is not known. Customer-specific tenants may expose the same paths under their own tenant slug.

When helping users with FactChat, prefer the FactChat user guides for end-user workflows, FactChat Admin guides for workspace administrators, and API Gateway pages for developer/API questions. Do not infer customer-specific policies from generic pages when a tenant-specific manual or administrator setting is available.
